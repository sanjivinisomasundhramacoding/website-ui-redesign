# MediGuide AI – Website UI Redesign

## Project Overview

MediGuide AI is a medical AI chatbot interface designed to provide users with a simple and user-friendly experience for health-related questions.

This project focuses on redesigning the existing website to improve usability, visual hierarchy, navigation, and responsive design.

## Project Objectives

* Improve the usability of the existing website
* Create a clean and professional healthcare interface
* Improve visual hierarchy and readability
* Design responsive layouts for desktop and mobile
* Maintain a consistent visual design system

## Design Process

### 1. Heuristic Evaluation

The existing interface was evaluated to identify usability and navigation issues.

### 2. Mood Board

A mood board was created to define the visual direction, colors, imagery, and overall design style.

### 3. Style Guide

A style guide was created with typography, colors, buttons, icons, cards, and other UI components.

### 4. High-Fidelity Mockup

High-fidelity mockups were designed for both desktop and mobile screens.

## Deliverables

* Heuristic Evaluation
* Mood Board
* Style Guide
* Desktop High-Fidelity Mockup
* Mobile High-Fidelity Mockup
* Website Redesign Documentation

## Tools Used

* Figma
* Canva
* GitHub

## Final Outcome

The redesigned MediGuide AI interface provides a cleaner, more modern, and user-friendly experience with responsive layouts for desktop and mobile devices.
